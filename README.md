# QA Manual Testing Portfolio

Este repositorio contiene dos casos de prueba manuales y un reporte de bug simulado, desarrollados como parte de mi formacion en aseguramiento de calidad de software (QA).

Su objetivo es demostrar mis habilidades en el diseño y documentación de pruebas positivas (Happy Path), pruebas negativas (Negative Testing) y reportes de defectos.

## Contenido del proyecto

### Casos de prueba (Test Cases)

- **[TC-001 - Login exitoso](test-cases/TC-001-login-exitoso.md):** Verifica que un usuario registrado pueda iniciar sesión correctamente utilizando un correo electrónico y una contraseña validos.

- **[TC-002 - Registro con contraseña invalida](test-cases/TC-002-registro-password-invalida.md):** Verifica que el sistema rechace el registro de un nuevo usuario cuando introduce una contraseña de menos de 8 caracteres.

### Reporte de bugs (Bug Reports)

- **[BUG-001 - Error de inicio de sesión (simulado)](bug-reports/BUG-001-login.md):** Documenta un defecto simulado en el que el sistema rechaza el inicio de sesión de un usuario registrado, aunque introduce credenciales validas.

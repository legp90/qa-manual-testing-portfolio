TC-001 — Login exitoso con credenciales validas

Objetivo: Verificar que el sistema permita iniciar sesión a un usuario registrado cuando introduce un correo electrónico y una contraseña correctos.

Precondiciones: El usuario debe tener una cuenta activa en la aplicacion.

Datos de prueba: Correo y contraseña validos de una cuenta de pruebas.

Pasos:
1. Abrir la tienda online. 
2. Hacer clic en el Login
3. Introducir el correo y contraseña validos.
4. Hacer clic en Ingresar.

Resultado esperado: El sistema permite al usuario acceder correctamente al sistema.

Estado: Not Run.
